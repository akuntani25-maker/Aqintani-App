# Panduan Print Struk - UD. AQIN TANI

## ✅ Ukuran Kertas yang Didukung

### 1. **Thermal 48mm** (EPSON D58UBT-S)
- Ukuran: 48mm x 210mm
- Lebar efektif: ~44mm (dengan margin)
- Karakter per baris: ~18-20 karakter
- Font size: 7-9px (sangat compact)
- **Cocok untuk**: EPSON D58UBT-S, thermal mini

### 2. **Thermal 58mm** (Standard POS)
- Ukuran: 58mm x variable
- Lebar efektif: ~54mm
- Karakter per baris: ~32 karakter
- Font size: 9-10px
- **Cocok untuk**: Thermal printer standard, POS 58 RPP02N

### 3. **A4** (Laser/Inkjet)
- Ukuran: 210mm x 297mm
- Full page receipt
- Font size: Normal (14-16px)
- **Cocok untuk**: Printer laser, inkjet, office printer

## 🎯 Cara Print Struk (Print Preview)

### Setup Awal - Pilih Ukuran Kertas:

1. Login sebagai **Admin**
2. Buka menu **"Printer"** di sidebar
3. Scroll ke **"Ukuran Kertas Printer"**
4. Pilih ukuran sesuai printer Anda:
   - **48mm** → EPSON D58UBT-S / Thermal Mini
   - **58mm** → Thermal Standard POS
   - **A4** → Laser / Inkjet
5. ✅ Setting tersimpan otomatis

### Flow Transaksi:

1. **Tambah Produk ke Keranjang**
   - Di halaman POS, tambahkan produk yang dibeli
   - Bisa scan barcode atau klik produk

2. **Checkout**
   - Klik tombol "Checkout"
   - Pilih metode pembayaran (Tunai/Kartu/E-wallet)
   - Masukkan jumlah bayar

3. **Proses Pembayaran**
   - Klik tombol "Bayar"
   - ✅ Transaksi berhasil!

4. **Redirect ke Receipt Preview** 🎉
   - Otomatis redirect ke halaman preview struk
   - Struk ditampilkan dalam format siap cetak
   - Terlihat professional seperti struk asli

5. **Print Struk**
   - Klik tombol **"Print Struk"** di kanan atas
   - Dialog print browser akan muncul
   - Pilih printer yang ingin digunakan:
     - ✅ **EPSON D58UBT-S** (thermal printer Anda)
     - ✅ Laser printer
     - ✅ Inkjet printer
     - ✅ Print to PDF (untuk simpan digital)
   - Klik "Print"
   - ✅ Struk tercetak!

6. **Kembali ke POS**
   - Klik tombol "Kembali ke POS" di kiri atas
   - Siap untuk transaksi berikutnya

## 🖨️ Setting Printer di Windows (Untuk Thermal 48mm)

### Untuk EPSON D58UBT-S (48mm):

**Step 1: Install Driver**
1. Download driver EPSON D58 dari website EPSON resmi
2. Install driver sesuai instruksi
3. Restart komputer jika diminta

**Step 2: Set Custom Paper Size**
1. Control Panel → Devices and Printers
2. Right-click printer **EPSON D58UBT-S**
3. Pilih **"Printing Preferences"**
4. Tab **"Page Setup"** atau **"Paper"**
5. Pilih **"Custom"** paper size
6. Set ukuran:
   - **Width: 48mm**
   - **Height: 210mm** (atau Auto)
7. Save as **"Thermal48mm"**
8. Click OK

**Step 3: Set as Default**
1. Right-click printer EPSON D58UBT-S
2. **"Set as default printer"**
3. ✅ Done!

**Via USB:**
1. Colok kabel USB ke komputer
2. Windows akan auto-detect
3. Follow Step 2 & 3 di atas

**Via Bluetooth:**
1. Nyalakan Bluetooth printer (tekan tombol BT)
2. Windows Settings → Bluetooth & Devices
3. Add Device → Bluetooth
4. Pilih "EPSON D58" atau "D58UBT"
5. Pair device (PIN biasanya: 0000 atau 1234)
6. Follow Step 2 & 3 di atas

## 💡 Tips & Tricks

### 1. Print Cepat
- Tekan `Ctrl + P` di halaman receipt preview
- Langsung buka dialog print

### 2. Print ke PDF
- Pilih "Save as PDF" / "Microsoft Print to PDF"
- Untuk arsip digital atau email ke customer

### 3. Setting Print Size
- Untuk thermal printer 58mm:
  - Pilih printer EPSON D58
  - Ukuran kertas biasanya auto-detect
  - Atau pilih "Custom" → Width: 58mm

### 4. Print Multiple Copies
- Di dialog print, set "Copies" ke jumlah yang diinginkan
- Bisa print 2-3 copy untuk customer & arsip

### 5. Shortcut Keyboard
- `Ctrl + P` = Print
- `Alt + ←` = Back to POS
- `Esc` = Close print dialog

## 🔧 Troubleshooting

### Printer tidak terdeteksi
**Solusi:**
1. Pastikan printer ON dan terhubung
2. Check di Settings → Printers & Scanners
3. Pastikan status "Ready"
4. Restart printer jika perlu
5. Refresh browser (F5)

### Struk terpotong
**Solusi:**
1. Pilih ukuran kertas yang sesuai (58mm untuk thermal)
2. Set orientation: Portrait
3. Set margins: Minimum
4. Uncheck "Headers and footers"

### Print lambat
**Solusi:**
1. Normal untuk thermal printer (~5 detik)
2. Pastikan driver up to date
3. Cek kabel USB tidak longgar

### Hasil print blur/tidak jelas
**Solusi:**
1. Bersihkan print head
2. Ganti kertas thermal yang baru
3. Check kualitas print di printer settings
