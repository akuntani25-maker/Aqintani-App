## 🎯 Cara Print Struk (Print Preview)

### Flow Transaksi:

1. **Tambah Produk ke Keranjang**
   - Di halaman POS, tambahkan produk yang dibeli
   - Bisa scan barcode atau klik produk

2. **Checkout**
   - Klik tombol "Checkout"
   - Pilih metode pembayaran (Tunai/Kartu/E-wallet)
   - Masukkan jumlah bayar

3. **Proses Pembayaran**
   - Klik tombol "Bayar"
   - ✅ Transaksi berhasil!

4. **Redirect ke Receipt Preview** 🎉
   - Otomatis redirect ke halaman preview struk
   - Struk ditampilkan dalam format siap cetak
   - Terlihat professional seperti struk asli

5. **Print Struk**
   - Klik tombol **"Print Struk"** di kanan atas
   - Dialog print browser akan muncul
   - Pilih printer yang ingin digunakan:
     - ✅ **EPSON D58UBT-S** (thermal printer Anda)
     - ✅ Laser printer
     - ✅ Inkjet printer
     - ✅ Print to PDF (untuk simpan digital)
   - Klik "Print"
   - ✅ Struk tercetak!

6. **Kembali ke POS**
   - Klik tombol "Kembali ke POS" di kiri atas
   - Siap untuk transaksi berikutnya

## 🖨️ Setting Printer di Windows

### Untuk EPSON D58UBT-S:

**Via USB:**
1. Colok kabel USB ke komputer
2. Windows akan auto-install driver
3. Jika tidak auto-install:
   - Download driver EPSON D58 dari website EPSON
   - Install driver
   - Restart komputer

**Via Bluetooth:**
1. Nyalakan Bluetooth printer (tekan tombol BT)
2. Buka Settings → Bluetooth & Devices
3. Add Device → Bluetooth
4. Pilih "EPSON D58" atau "D58UBT"
5. Pair device

**Set as Default Printer:**
1. Settings → Printers & Scanners
2. Klik printer EPSON D58UBT-S
3. Klik "Set as default"
4. ✅ Sekarang struk akan otomatis cetak ke printer ini!

## 💡 Tips & Tricks

### 1. Print Cepat
- Tekan `Ctrl + P` di halaman receipt preview
- Langsung buka dialog print

### 2. Print ke PDF
- Pilih "Save as PDF" / "Microsoft Print to PDF"
- Untuk arsip digital atau email ke customer

### 3. Setting Print Size
- Untuk thermal printer 58mm:
  - Pilih printer EPSON D58
  - Ukuran kertas biasanya auto-detect
  - Atau pilih "Custom" → Width: 58mm

### 4. Print Multiple Copies
- Di dialog print, set "Copies" ke jumlah yang diinginkan
- Bisa print 2-3 copy untuk customer & arsip

### 5. Shortcut Keyboard
- `Ctrl + P` = Print
- `Alt + ←` = Back to POS
- `Esc` = Close print dialog

## 🔧 Troubleshooting

### Printer tidak terdeteksi
**Solusi:**
1. Pastikan printer ON dan terhubung
2. Check di Settings → Printers & Scanners
3. Pastikan status "Ready"
4. Restart printer jika perlu
5. Refresh browser (F5)

### Struk terpotong
**Solusi:**
1. Pilih ukuran kertas yang sesuai (58mm untuk thermal)
2. Set orientation: Portrait
3. Set margins: Minimum
4. Uncheck "Headers and footers"

### Print lambat
**Solusi:**
1. Normal untuk thermal printer (~5 detik)
2. Pastikan driver up to date
3. Cek kabel USB tidak longgar

### Hasil print blur/tidak jelas
**Solusi:**
1. Bersihkan print head
2. Ganti kertas thermal yang baru
3. Check kualitas print di printer settings
